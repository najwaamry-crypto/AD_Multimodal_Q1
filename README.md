# AD_Multimodal_Q1

Reproducible multimodal Alzheimer's disease research project.

## Modalities
- Structural MRI
- FDG-PET
- Clinical, demographic and genetic variables

## Primary task
Three-class classification:
CN / MCI / DEM

## Main scientific objective
Quantify the independent and complementary contribution of MRI and FDG-PET
beyond clinical and diagnosis-linked cognitive information.

## Development dataset
ADNI

## Status
New pipeline started from scratch.
No model training has started.
