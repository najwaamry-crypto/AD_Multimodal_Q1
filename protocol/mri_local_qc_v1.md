# MRI Local Download, Conversion, and QC Protocol v1

## Scope

This document records the local verification of the QC-selected T1 MRI cohort
before any model-dependent preprocessing or training.

## Download verification

The locked MRI download manifest contained 825 ADNI Image IDs corresponding to
822 previously selected LONI MRI series and 822 unique subjects.

The IDA collection was verified against the locked manifest before download:

- expected Image IDs: 825
- IDA Image IDs: 825
- missing IDs: 0
- unexpected IDs: 0
- exact ID match: yes

All 10 IDA ZIP archives passed integrity testing before extraction.

After extraction:

- expected MRI Image IDs: 825
- unique MRI Image IDs found locally: 825
- missing expected IDs: 0
- unexpected IDs: 0
- duplicate Image-ID directories: 0

## DICOM characteristics

All 825 MRI Image IDs were readable.

- empty Image-ID directories: 0
- modality: MR for all 825
- unique SeriesInstanceUID values: 825

The cohort is intentionally heterogeneous because it spans ADNI1, ADNIGO/ADNI2,
and ADNI3 acquisitions. Multiple matrix sizes, voxel spacings, slice counts, and
field strengths were therefore retained and were not treated as QC failures by
themselves.

Twelve Image IDs contained a single Enhanced MR multi-frame DICOM rather than
one DICOM file per slice. These scans contained 170 or 211 frames and converted
successfully with dcm2niix.

## DICOM-to-NIfTI conversion

Conversion used dcm2niix v1.0.20260416.

Results:

- MRI Image IDs attempted: 825
- successful conversions: 825
- failed conversions: 0

All resulting NIfTI files were readable.

Global geometry audit:

- NIfTI files: 825
- invalid or unreadable geometry: 0
- all volumes were three-dimensional
- all voxel dimensions were positive
- all affine matrices contained finite values

The observed variation in image dimensions and voxel spacing was retained as
native acquisition heterogeneity and will be handled explicitly during the
preprocessing stage.

## Multiple Image IDs within three selected LONI series

Three QC-selected LONI series were associated with two downloadable Image IDs:

- RID 4138, series 200478:
  - I389652
  - I389660

- RID 4468, series 213644:
  - I416046
  - I416053

- RID 4571, series 216492:
  - I420552
  - I420554

Local DICOM metadata showed that each pair represented distinct same-day
acquisitions with different acquisition times and SeriesInstanceUID values.

All six acquisitions:

- converted successfully,
- had valid geometry,
- showed no severe truncation,
- showed no gross motion artifact,
- showed no major ghosting on local visual QC.

Because neither acquisition in a pair had a clear exclusion-level QC defect, a
deterministic tie-break was fixed before model training:

> retain the earliest same-day acquisition.

The retained Image IDs are therefore:

- RID 4138 -> I389652
- RID 4468 -> I416046
- RID 4571 -> I420552

The alternative Image IDs remain preserved in the raw/interim data and are not
deleted.

## Final locked MRI analytic selection

After the local tie-break:

- final MRI selections: 822
- unique RIDs: 822
- unique selected LONI series: 822

The final selection is stored in:

`data/interim/imaging_download_manifests/mri_final_image_selection_v1.csv`

and is reproducibly generated by:

`src/cohort/26_finalize_mri_local_selection.py`

## Locking rule

The MRI selection and tie-break decisions are fixed before model training and
must not be changed in response to downstream classification performance.
